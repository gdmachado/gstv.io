A running list of the hardware, software, and gear I actually use day-to-day. Inspired by [uses.tech](https://uses.tech).

## Computer

- **Laptop:** 16" [MacBook Pro](https://www.apple.com/macbook-pro/), M3 Max.
- **Desktop:** custom build, [Intel i9-14900K](https://www.intel.com/content/www/us/en/products/sku/236773/intel-core-i9-processor-14900k-36m-cache-up-to-6-00-ghz/) + [NVIDIA RTX 4090](https://www.nvidia.com/en-us/geforce/graphics-cards/40-series/rtx-4090/). Dual-boot, Windows for gaming, [Arch Linux](https://archlinux.org) for everything else.
- **Display:** [ASUS ROG Swift OLED PG42UQ](https://rog.asus.com/monitors/40-to-43-inches/rog-swift-pg42uq-model/). 42" 4K OLED.
- **Keyboard:** [Rama Works M60-A SEQ2](https://rama.works) with [Gazzew Bobagum silent linears](https://www.mechmods.co.uk/products/gazzew-bobagum-silent-linear-switches). US layout.
- **Mouse:** [Razer Naga V2 Pro](https://www.razer.com/gaming-mice/razer-naga-v2-pro).
- **Headphones:** [Audeze LCD-2 Classic](https://www.audeze.com/products/lcd-2-classic).
- **Mic:** [Shure SM7B](https://www.shure.com/en-US/shop/microphones/sm7b).
- **DAC / amp:** [Topping D30 Pro](https://www.toppingaudio.com) + [A30 Pro](https://www.toppingaudio.com) stack.

## Editor & terminal

- **Editor:** [Zed](https://zed.dev) for everything. [RustRover](https://www.jetbrains.com/rust/) for Rust, [GoLand](https://www.jetbrains.com/go/) for Go, [IntelliJ](https://www.jetbrains.com/idea/) for the rare Kotlin project.
- **Editor theme:** [Catppuccin Mocha](https://catppuccin.com/).
- **Terminal:** [Ghostty](https://ghostty.org/).
- **Shell:** [zsh](https://www.zsh.org) + [starship](https://starship.rs) prompt + [zinit](https://github.com/zdharma-continuum/zinit) for plugins.
- **Code font:** [JetBrains Mono](https://www.jetbrains.com/lp/mono/) most of the time. [Geist Mono](https://vercel.com/font) where the app picks it.

## Dev tools

- **Browser:** [Firefox](https://www.mozilla.org/firefox/).
- **Git client:** [lazygit](https://github.com/jesseduffield/lazygit).
- **Containers:** [colima](https://github.com/abiosoft/colima).
- **Runtimes:** [mise](https://mise.jdx.dev) for everything.
- **Couldn't live without:** [ripgrep](https://github.com/BurntSushi/ripgrep), [fzf](https://github.com/junegunn/fzf), [jq](https://jqlang.org/), [uv](https://docs.astral.sh/uv/).
- **Languages I reach for most:** [Python](https://www.python.org), [Rust](https://www.rust-lang.org).

## AI / ML

- **Frameworks:** [PyTorch](https://pytorch.org), [Hugging Face](https://huggingface.co) (Transformers + Datasets + Hub).
- **Local models:** [llama.cpp](https://github.com/ggml-org/llama.cpp), [Ollama](https://ollama.com) on top, [LM Studio](https://lmstudio.ai) for the GUI moments.
- **Inference:** [vLLM](https://github.com/vllm-project/vllm) when I need serving with throughput.
- **Notebooks:** [Jupyter](https://jupyter.org). Eyeing [marimo](https://marimo.io).
- **Experiments:** [Weights & Biases](https://wandb.ai).
- **APIs:** [OpenRouter](https://openrouter.ai) when remote models are easier (one API key, every provider).
- **CLI:** Simon Willison's [llm](https://llm.datasette.io) for quick queries from the terminal.
- **Coding agents:** [Claude Code](https://www.anthropic.com/claude-code), [Codex](https://github.com/openai/codex), [OpenCode](https://opencode.ai). Often run in parallel via [Conductor](https://conductor.build).
- **Vector store:** [pgvector](https://github.com/pgvector/pgvector) on Postgres.

## Data

- **DataFrames:** [Polars](https://pola.rs).
- **OLAP:** [StarRocks](https://www.starrocks.io) and [Snowflake](https://www.snowflake.com) at work, [ClickHouse](https://clickhouse.com) when I need something local and fast.
- **General-purpose:** [PostgreSQL](https://www.postgresql.org). Love it as much as the next dev.
- **Multi-model:** [SurrealDB](https://surrealdb.com), for the startup.
